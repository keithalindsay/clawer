# 🦞 Clawer.ai — Launch Day Checklist

_Product Hunt launches at 12:01am Pacific Time. Plan around that._

---

## DAY BEFORE (T-24h)

### Product Hunt Setup
- [ ] Submit PH listing (needs to be submitted and scheduled, not just drafted)
- [ ] Upload all assets: logo (240×240), gallery screenshots (1270×760)
- [ ] Set tagline, short description, full description from `producthunt.md`
- [ ] Add all 5 key features
- [ ] Set categories: Artificial Intelligence, Productivity, SaaS
- [ ] Write your first comment and save it as draft — post it at 12:05am launch night
- [ ] Add team members to the PH listing (if any)
- [ ] Double-check the URL goes to clawer.ai (not a broken redirect)

### Screenshots to prepare
- [ ] Homepage hero
- [ ] Team selection / template picker
- [ ] Dashboard with an active team visible
- [ ] WhatsApp or Telegram connection screen (blur any real numbers)
- [ ] Mobile view of chatting with the team

### X/Twitter
- [ ] Set up profile: handle, bio, header image, website link (from `x-profile.md`)
- [ ] Draft all 10 tweets in thread composer — don't post yet
- [ ] Follow relevant accounts: indie hackers, PH hunters, AI builders
- [ ] DM 3-5 friends/supporters: "Launching tomorrow. Would love an upvote and comment."

### Personal prep
- [ ] Block 8 hours for launch day engagement (no meetings, no distractions)
- [ ] Set phone to alert on PH comments and X mentions
- [ ] Eat something. Sleep. Seriously.

---

## LAUNCH MORNING

### 12:01am PT — Go Live
- [ ] PH listing should auto-publish (confirm it's live)
- [ ] Post your first maker comment immediately (the personal one from `producthunt.md`)
- [ ] Post Tweet 1 of the X thread — let the full thread rip right now if you're awake, or schedule for 6am

### 6:00am PT — Morning Push (best engagement window)
- [ ] Post the full X thread if you haven't already
- [ ] Share to LinkedIn (rewrite slightly — LinkedIn audience is more formal, emphasize business ROI)
- [ ] Post in relevant Slack/Discord communities:
  - Indie Hackers
  - HN's Show HN (post separately: "Show HN: clawer.ai — managed AI Teams with WhatsApp/Telegram")
  - Any founder/builder Discords you're in
  - r/SideProject or r/entrepreneur if you're comfortable

### 7:00am PT — Check and engage
- [ ] Reply to every PH comment within 5 minutes during morning hours
- [ ] Thank upvoters if they comment
- [ ] Ask a question back to anyone who comments — keep threads alive
- [ ] Retweet anyone who shares the launch with their audience

### 9:00am PT — Mid-morning update
- [ ] Post a quote tweet: "2 hours in, here's what's happening..." (share early signup count or PH rank)
- [ ] DM anyone who said they'd check it out: "Hey, just went live — it's up on Product Hunt if you get a sec"

- [ ] Check PH comments — reply to all, no exceptions
- [ ] Check X mentions — thank, engage, retweet good ones
- [ ] Monitor rank — if dropping, post mid-day update tweet

## POST-LAUNCH (next 48h)

### Day after
- [ ] Post a "Day 1 recap" tweet: what happened, what surprised you, what you're building next
- [ ] Reply to any PH comments you missed
- [ ] DM people who upvoted and left thoughtful comments — genuine thank you, offer to get feedback
- [ ] Post on Indie Hackers: "We launched on Product Hunt — here's what happened"

### Week after
- [ ] Follow up with anyone who signed up and hasn't activated (email if you have it)
- [ ] Ship the task board — tweet about it, reference the launch ("we said this week, here it is")
- [ ] Write a short launch retrospective (even just for yourself) — what worked, what didn't
- [ ] Update PH listing with any metrics you're comfortable sharing
