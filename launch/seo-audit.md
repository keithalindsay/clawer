### ⚡ Rendering Issue: SPA vs SSR

**This is the biggest SEO problem on the site.**

Every blog page currently returns:
```html
<title>OpenClaw Security: Why 42,000+ Instances Are Exposed</title>
<!-- ...but body content is: -->
<div>Loading...</div>
```

The `<title>` tag IS rendered server-side (Next.js does hydrate this), but the **body text** is not. This means:
- Google may index only the title with no content
- No word count signal → page may not rank for anything
- Meta description renders correctly from `<head>`, but no `<article>` body text

**Fix:** In Next.js App Router, ensure blog post pages use:
1. `export const dynamic = 'force-static'` or `generateStaticParams()`
2. All content rendered in server components
3. No client-side data fetching for the blog post body

## Critical Bugs Found

These are the most impactful issues discovered during this audit:

### 🚨 Bug #1: /pricing Canonical Points to Homepage
**File:** Next.js metadata for `/pricing` route  
**Current:** `<link rel="canonical" href="https://clawer.ai"/>`  
**Should be:** `<link rel="canonical" href="https://clawer.ai/pricing"/>`  
**Impact:** Google sees `/pricing` as a duplicate of the homepage and will not rank it independently. The pricing page is essentially invisible in search results.

### 🚨 Bug #2: Blog Pages Render "Loading..." for Crawlers
**File:** `/blog/[slug]` route rendering  
**Current:** Page HTML body contains `<p>Loading...</p>` — content is client-side only  
**Should be:** All blog post content server-rendered (SSR or SSG via `generateStaticParams`)  
**Impact:** Google indexes these pages with no content. Zero chance of ranking for any target keyword.

### ⚠️ Bug #3: Duplicate Title + Meta Description on /pricing
**Current:** Both / and /pricing share identical `<title>` and `<meta name="description">`  
**Impact:** Duplicate content signals, lower quality scores, confusion about which page to rank.

### ⚠️ Bug #4: Twitter Title ≠ OG Title on Homepage
**OG Title:** "Clawer.ai — Hosted OpenClaw, Personal AI Assistant"  
**Twitter Title:** "Clawer.ai — Your AI Team, Ready to Work"
